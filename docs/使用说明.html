休息小助手

一只住在托盘里的小猫，陪你番茄式工作与休息

v1.4 · 本地离线 · 不联网 · 数据只存本机

一、它是什么

一个轻量的桌面计时小工具（基于 Electron），常驻系统托盘，按「工作 → 休息」的节奏提醒你起身活动。所有数据只保存在你自己的电脑上，不联网、不上传、无账号。

默认节奏工作 45 分钟 → 短休 5 分钟，
每 4 轮来一次 15 分钟长休（都可改）
随时可走开会 / 领导在场时，
一键进入「会议模式」静音提醒

二、快速开始

Windows

  1. 拿到 休息小助手 1.0.0.exe（约 100MB，单文件）。
  2. 双击运行，无需安装、无需联网。
  3. 首次启动，Windows 可能提示「未知发布者」→ 点「更多信息 → 仍要运行」。
  4. 右下角托盘出现小猫图标即已启动。

macOS / Linux

本工具主要面向 Windows 与 Linux（托盘）。若在某些桌面环境（如原生 GNOME）看不到托盘图标，可直接用快捷键 Ctrl+Alt+R 唤出面板。

三、界面一览

每天第一次打开：先问一句「开始工作吗」

程序在空闲状态启动时（比如每天早上的第一次打开），不会直接开始计时，而是先弹一个确认窗：

  • 开始工作 — 点击后才开始本轮计时，并自动显示主面板。
  • 直接关掉（Esc 或 ×）— 什么都不开始，程序留在托盘待命；之后可用 Ctrl+Alt+R 唤出面板点「开始」。

如果你同一天中途关掉又打开，而上次那轮工作还没走完，程序会接着走（断点续跑），不会重新问你。只有跨天了才会清零。

主面板（点托盘图标或按快捷键打开）

大圆环 + 倒计时当前阶段与剩余时间；面板里是你家的猫——它会呼吸、轻轻摇摆、每隔几秒眨一次眼，休息时闭眼一动不动；鼠标移到它身上会歪头「看过来」。两只猫按抽签方式轮换（公平保证每猫各占一半，且不会连着三轮都是同一只，约七成轮次能看到两只）。静音时它安静下来变灰。
已超时（橘红）工作到点、弹窗挂着等你决定时，圆环会变成橘红色并保持满环，时间从 00:00 变成往上走的「已超时 mm:ss」。这段时间照样计入今日工时（含点「稍后 5 分钟」的等待、会议模式压住不弹的那段）；点了「去休息」或「跳过休息」就立即停止。
休息结束后的等待点击期不计入工时——那段时间你是在休息。
今日已工作进度条满格代表 8 小时。6 小时内是薄荷绿，6→8 小时由绿经琥珀黄渐变为红，超过 8 小时变红并显示「已加班：xx」（文字同步变红）。进度条始终保持满格，超出部分靠文字体现。
今日统计四格工作轮 / 已休息 / 跳过工作 / 跳过休息，跨天自动清零。
开始 / 暂停控制整个计时；暂停会冻结倒计时与工时统计。
跳过本轮工作中=跳过工作；待决策=去休息；休息中=跳过休息。
会议模式下拉选择静音方式，详见下一节。
设置 / 退出打开设置面板；彻底关闭程序。

提醒弹窗（到点自动弹出）

工作到点时会温柔地提醒你：

  • 好的，去休息 — 开始短休/长休倒计时。
  • 稍后 5 分钟 — 5 分钟后再提醒一次（这段等待时间继续计入工时）。
  • 跳过休息 — 直接进入下一轮工作（计入「跳过休息」）。

弹窗挂着不点也没关系：这段时间算你还在干活，计时不会停，面板会显示递增的「已超时」。

休息到点时，会先问你要不要开始工作：

  • 开始工作 — 点击后才开始本轮工作计时。
  • 再休息 5 分钟 — 继续休息 5 分钟后再问。

任意时刻按 Esc 或点右上角 × 可立刻关掉弹窗；开会/领导经过时一键秒关。

猫的小动作：工作结束的弹窗弹出时，里面的猫会先伸个懒腰再闭眼休息；鼠标移到面板的猫身上，它会歪头「看过来」。
工作永远不会自动开始——每次都是从休息转入工作时，都需要你点一次「开始工作」，避免你还没准备好就进入倒计时。

四、会议模式（静音提醒）

开会、领导在旁时担心弹窗打扰？在面板或托盘菜单选一种静音方式：

到工作时间结束静音到本轮工作结束；一旦时间到就弹窗提醒你。（推荐）
15 / 30 / 60 分钟定时静音，到期后若有到点提醒则补弹一次。
手动恢复一直静音，直到你手动选「关」才恢复；期间不弹窗。
会议模式只静音弹窗、时钟照走，工作时长与今日工时照常累计。如果你希望开会期间既不计时也不计工时，请改用「暂停」。

五、设置

点面板底部「设置」打开。所有改动即时保存，保存后窗口会自动关闭。

工作时长一轮专注工作的分钟数（1–240）。
短休息时长每轮之间短休息的分钟数（1–60）。
长休息时长长休息的分钟数（5–120）。
第几轮后长休每完成几轮工作安排一次长休息（2–8）。
时长改动生效下一轮（本轮按原时长走完）或立即（按新时长重算当前剩余；已超时则立即结束本轮）。
开机自动启动开机自动在托盘启动。
⚠️ 目前只在 Windows 上生效。Linux 上这个选项会保存但不起作用——系统的开机自启需要往 ~/.config/autostart/ 放一个 .desktop 文件，这个功能还没做。Linux 上想开机自启的话，把 休息小助手-*.AppImage 拖进系统设置的「开机启动 / 自启动」应用列表里即可（路径不能变）。

六、配置文件位置

程序的数据都在系统的用户配置目录下，目录名随产品名 休息小助手：

WindowsC:\Users\<你的用户名>\AppData\Roaming\休息小助手\
Linux~/.config/休息小助手/

里面有 3 个文件：

  • config.json — 各项设置（可直接编辑，改完重启生效）。
  • state.json — 计时断点，用于关掉程序后重开继续。
  • stats.json — 今日统计，跨天自动清零。
这些文件只是这个工具自己的数据，与系统无关。想重置一切，删掉这个目录即可，下次启动会重新生成。

七、快捷键与托盘

Ctrl+Alt+R随时唤出/隐藏主面板（不依赖托盘，最稳妥）。
Esc在提醒弹窗按下即关闭该弹窗。
托盘左键打开 / 收起面板。
托盘右键Windows 上弹出菜单（开始/暂停、跳过、会议模式、设置、退出）；Linux 上可能表现为打开面板。
关掉窗口 ≠ 退出。点面板的 × 只是收起到托盘，程序仍在后台计时。要真正退出，请用面板底部「退出」按钮，或托盘右键菜单里的「退出小程序」。

八、常见问题

找不到托盘图标？部分桌面环境（如原生 GNOME）不显示托盘。用快捷键 Ctrl+Alt+R 唤出面板即可。
托盘右键没反应/菜单空白？某些桌面（实测 UKUI）会吞掉托盘右键。改用左键点图标或快捷键打开面板即可，功能完全一样。
程序怎么完全关闭？面板底部「退出」按钮，或托盘右键「退出小程序」。
换电脑 / 搬数据把第 6 节那个目录下的 3 个 json 拷到新电脑对应位置即可（路径见上）。

九、后续规划

当前版本专注「安静地提醒」。后续计划加入桌宠：一只真实小猫形象在桌面走来走去，代替静态弹窗来提醒你休息。当前版本已为该功能预留了接口与素材目录，不影响日后平滑升级。
