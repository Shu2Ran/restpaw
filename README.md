# RestPaw · 休息小助手

> 轻量可爱的番茄式休息提醒小工具。离线单机，托盘常驻，不联网、无账号、不上传任何数据。

一只猫陪你工作，到点提醒你抬头看看远处。界面里的猫会呼吸、轻轻摇摆、每隔几秒眨一次眼；
休息的时候它闭眼睡过去。

---

## 特性

- **番茄节奏**：工作 45 分钟 → 短休 5 分钟，每 4 轮 → 长休 15 分钟，时长全部可改
- **休息永远需要你点一下「开始工作」**——不会在你还没准备好时自动开始倒计时
- **会议模式**：一键静音 15/30/60 分钟或到本轮工作结束，时钟照走、只静音提醒，解除时补弹
- **今日工时进度条**：6 小时内薄荷绿，6→8 小时琥珀渐变，超过 8 小时变红并显示「已加班」
- **等决策期间也算工时**：工作结束弹出「去不去休息」而你还没点时，时间继续计入，圆环转橘红、时钟显示递增的「已超时」
- **换猫是公平的**：抽签袋策略，每一周期严格等分，长期不会一直只看到一只猫
- **断点续跑**：存的是绝对截止时间戳，休眠、杀进程、重启都不丢进度；跨天自动归零
- **完全离线**：不联网、无账号、无遥测，设置与统计只存在本机

## 安装

### Windows

下载 `休息小助手-2.2.0.exe`（便携单文件，双击即用，无需安装），
放到任意目录或 U 盘都行。数据存在 `%APPDATA%\休息小助手\`。

首次运行 Windows 可能提示「已保护你的电脑」——点「更多信息」→「仍要运行」即可
（未做代码签名）。

### Linux

下载 `休息小助手-2.2.0.AppImage`：

```bash
chmod +x 休息小助手-2.2.0.AppImage
./休息小助手-2.2.0.AppImage
```

数据存在 `~/.config/休息小助手/`。

### 从源码运行

```bash
npm install
npm start        # 会先重建图标再启动
```

需要 Node.js 18+。Electron 44 首次安装约 400MB。

## 换成你自己的猫

**本项目作者的两只猫是真实存在的动物，形象属个人素材，没有随代码分发。**
所以你下载到的程序用的是**内联手绘 SVG 猫**——功能完全一样，只是长得不一样。

换成你自己的猫很简单：

### 方式 A · 手动（不需要装任何东西，推荐）

1. 准备两张 **512×512、带透明通道**的 PNG：
   - `<你的猫id>-open.png` —— 睁眼
   - `<你的猫id>-closed.png` —— 闭眼
2. 拷进 `src/ui/assets/cats/`
3. 在同目录 `manifest.json` 的 `cats` 数组里加一项：

   ```json
   { "id": "mycat", "open": "mycat-open.png", "closed": "mycat-closed.png" }
   ```

4. 重启程序

### 方式 B · 素材管线（自动检测主体并裁切，需要 ImageMagick）

1. 原图放进 `cats-raw/mycat-open.png` 与 `cats-raw/mycat-closed.png`（**必须带透明通道**）
2. 在 `tools/build-cats.js` 的 `CAT_CONFIG` 加一项：

   ```js
   mycat: { out: 'mycat' },              // 不写 crop 就自动检测主体
   mycat: { out: 'mycat', crop: { x, y, w, h } },  // 或手工指定裁切框
   ```

   注意：键名是**原图文件名前缀**，`out` 才是最终的 id 和输出文件名。

3. `node tools/build-cats.js`

### 睁眼 ↔ 闭眼 对应关系

由 `src/ui/mascot.js` 的 `CLOSED_MOODS` 决定：

| 心情 | 用哪张图 | 出现时机 |
|---|---|---|
| `rest` | **闭眼 closed** | 短休 / 长休进行中 |
| `sleepy` | **闭眼 closed** | 暂停 |
| `happy` | **闭眼 closed** | 休息结束弹窗 |
| `work` | 睁眼 open | 工作中、每日首次确认弹窗 |
| `mute` | **睁眼 open** | 会议模式静音 |

两个容易踩的坑：

- **静音用的是睁眼图**——静音只是 CSS 灰化（`grayscale(35%)`），不切图。
  所以闭眼图只需要表达「休息 / 犯困 / 开心」三种。
- **闭眼图身兼两职**——它同时是「闭眼休息」和「眨眼动画」用的图。
  两张图的猫必须在画面上**位置、大小、角度完全一致**，否则眨眼时会「跳」。

### 素材规格

- **512×512**、PNG、**必须带 alpha 透明通道**（`build-cats.js` 会检查，缺了直接报错）
- 主体居中，四周留 **6% 边距**
- 实际显示很小——面板 **78px**、弹窗 **104px**。建议眼睛清晰、轮廓简洁

### 多只猫

往 `manifest.json` 的 `cats` 数组里加几项就行，**不用改任何代码**。
换猫走抽签袋：每只猫放 N 张（N = 猫总数），整袋洗牌、从尾部取、取空重装，
跨袋时若首尾撞车就精确交换一个元素。

| 猫数 | 袋大小 | 一周期 | 最长连号 | 公平性 |
|---|---|---|---|---|
| 2 | 4 | 4 轮 | **2 轮** | 每 4 轮严格 2:2 |
| 3 | 9 | 9 轮 | 3 轮 | 每 9 轮严格 3:3:3 |
| 4 | 16 | 16 轮 | 4 轮 | 每 16 轮严格 4:4:4:4 |
| N | N² | N² 轮 | N 轮 | 每 N² 轮严格等分 |

- 更强的保证是：**每 N² 轮，每只猫恰好出现 N 次**（不是「长期大致公平」，是精确公平）。
- ⚠️ 「绝不连续 3 轮同猫」这个说法**只在 2 只猫时成立**。N 只猫时袋里有 N 张同猫，
  最坏情况会连着出 **N 轮**。
- 换猫时机：启动时随机一只，之后**只在「工作 ↔ 休息」切换时**重抽。
  暂停、静音、同一阶段内的等待都不换。

### 没放素材会怎样

`manifest.json` 缺失、为空数组、或图片加载失败时，**自动回退到内联手绘 SVG 猫**，
功能不受影响。这条回退路径有两条自动化用例守着。

## 开发

```bash
npm test                    # 63 条单元测试（引擎 / 存储 / 抽签袋 / 路径），不需要 Electron
npm run test:ui             # 25 条 UI 端到端（Playwright 驱动 Electron）
node tools/ui-smoke.js 眨眼  # 只跑名字含「眨眼」的用例（用例名是中文子串匹配）
npm start                   # 开发运行
```

> **跑测试前务必确认没有 RestPaw 在跑。** 单例锁在 `src/main.js` 拿，
> 早于 `RESTPAW_USER_DATA` 覆盖，所以**任何**实例都会让每一条 UI 用例以 exitCode=0
> 瞬间退出，Playwright 报 `Target page, context or browser has been closed`——
> 那是「没跑起来」，不是「测试挂了」。

### 打包

```bash
export ELECTRON_MIRROR="https://registry.npmmirror.com/-/binary/electron/"
export ELECTRON_BUILDER_BINARIES_MIRROR="https://registry.npmmirror.com/-/binary/electron-builder-binaries/"
npm run dist:linux    # AppImage + tar.gz
npm run dist:win      # Windows 便携 exe
```

产物在 `out/`（不进版本库，约 983MB）。

> **镜像不是可选项。** `github.com` 在部分网络下连不通，
> electron-builder 会静默卡 10 分钟才抛超时。

## 已知限制

诚实起见，都列出来：

- **「开机自动启动」只在 Windows 上生效。** Electron 的 `app.setLoginItemSettings`
  在 Linux 是空操作（实测传 true 读回仍是 false，也不写 autostart 文件），
  所以在 Linux 上这个勾选框**只保存不生效**。Linux 想开机自启，
  把 AppImage 拖进系统设置的「开机启动」应用列表即可（路径不能变）。
- **Windows 便携版未做完整真机验证。** 托盘右键菜单、透明窗毛边、开机自启三项
  都是在 Linux 侧推断的，已在 Windows 上修好了开机自启的注册路径
  （portable 版跑在 `%TEMP%` 的解压目录里，照默认注册会静默失效），
  但**没有在 Windows 真机上跑过验证**。
- **不含猫图素材**（见上文「换成你自己的猫」），公开版是手绘 SVG 猫。
